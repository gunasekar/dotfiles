# Codename

Personal brand for configs and themes in this repo:

| | |
| --- | --- |
| **g9n** | Short form of gunasekaran — paths, scripts, theme names, future plugins |

Palette: Ayu-dark colours on true `#000000`.

| Surface | Name |
| --- | --- |
| Terminal.app profile | `g9n` (`terminal/.config/terminal/g9n.terminal`) |
| kitty colour scheme | g9n (inline in `kitty.conf`) |
| tmux chrome | `g9n.conf` |
| hunk theme | `theme = "g9n"` (`[themes.g9n]`) |
